# NovaCraft - Premium Corporate Agency & Tech Solutions

NovaCraft is a modern, responsive, glassmorphic corporate landing page and portfolio website built for digital agencies, tech startups, and software engineering firms.

## 🌟 Key Features

- **Modern Glassmorphic Aesthetic**: Acrylic frosted translucency, ambient gradients, floating badge cards, and smooth CSS motion design.
- **Dark & Light Mode**: Integrated theme switch with animated icon transitions and persistent `localStorage` preference state.
- **Sticky Navbar & ScrollSpy**: Smooth scrolling navigation with auto-highlighting active links and responsive collapse drawer.
- **Hero Typing Effect**: Dynamic cycling typewriter effect introducing core agency competencies.
- **Animated Counter Stats**: IntersectionObserver-powered numerical counters that count up when scrolled into view.
- **Services & Portfolio Modals**: Interactive Bootstrap 5 modals populating full service specifications and project case studies dynamically.
- **Pricing Billing Switch**: Toggle between monthly and annual plans with live 20% savings calculation.
- **FAQ Search Filter**: Real-time keyword filter for quick Q&A lookups.
- **Contact Form & Toast Notifications**: Client-side form validation with interactive toast feedback.
- **Scroll Reveal Animations**: Smooth scroll entrance effects across all cards and sections.
- **Mobile First & Responsive**: Optimized for phones, tablets, laptops, and ultra-wide displays.
